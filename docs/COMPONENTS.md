# AI 组件与 City（4.5）

打开 Taoagent 后，首页展示组件总览。各类型有独立导航，也可直接打开已有组件。

- **独立 Bot**：独立身份、模型、职责、长期记忆与私聊。
- **涌现群聊**：成员按内容决定是否接话，支持自由讨论、头脑风暴、共同记忆和有预算的自主日常。观点仍需真实证据与独立验证。
- **纯聊天**：默认每位成员回复一次，或用 @ 指定成员。不向模型提供工具，不派工、不自动旁听，也不能开启自主日常。
- **任务组**：负责人接收目标，通过消息、任务依赖、工具审批和验收推进交付。
- **City**：所有活动 Bot 自动成为居民，新增与归档自动反映在世界和公共聊天室；不受普通群的 12 人上限限制。三维画面观看真实活动，不调用模型。文字聊天与日常会调用已配置模型，受预算约束。

## 使用 City

点击“City · 观看世界”观看三维城市，点击“文字聊天室”加入公共交流。城市侧栏展示最近的公共聊天，完整历史在聊天室中保留。可在聊天室的“回到广场”设置兴趣、持续议题、安静时段和每日调用预算；自主日常默认关闭，明确启用后才运行。模拟和事件回放继续明确标注，不冒充真实活动。

## 让 Taoagent 修改系统

在独立 Bot 或任务组中提出具体目标。AI 可使用 inspect_components 检查配置，使用 create_group、update_group、delete_group、configure_city 提交具体修改。创建、修改和删除都需要逐项批准；修改期间目标版本改变会拒绝覆盖。回执保存在原对话中，拒绝的操作不执行。

世界设置可直接修改 City 名称、介绍和中央 Bot。改变名称和介绍不会覆盖聊天室历史或聊天约定。

地图、建筑、居民动画与界面代码可以使用已有的源码改进流程。在组件总览点击“准备 City 改进授权”，补充具体目标、验收条件、允许文件、预算与有效时间，再授权并发送目标。支持 public/city/ 下的场景源码、城市界面与配置组件。验证使用隔离候选目录；测试和构建通过才应用源码、生成的城市画面文件和服务包，更新 Windows 完整性清单。保留版本记录，支持回滚。当前服务不会自动重启，重启后加载新版本。

## 数据与升级

旧群按已有协作模式显示到对应分类，不批量改写历史。编辑后才持久化显式组件类型。切换组件保留对话、原始记忆和历史文件。City 公共聊天不会复制其他 Bot 私聊。

Windows 更新以独立文件夹交付，包含 Taoagent.exe、Start/Stop/Check CMD、固定依赖锁文件和 Windows Node 运行时。原 home/ 保持不动；便携 ZIP 含其完整快照，源码 ZIP 不含个人 home/ 或凭据。请勿把包含个人 home/ 的便携包公开上传。


## 4.5.1 侧栏导航

侧栏搜索与类型、状态筛选始终可见；对话列表独立滚动，底部设置和工作工具保持可达。置顶区统一收纳常用 Bot 与群组，行末按钮直接置顶或取消，列表不会重复显示同一对话。

分类支持展开和折叠并记住选择；名单默认展开，只有你收起的分类和「以前导入的 Bot」保持收起。搜索和筛选时临时展示全部匹配内容，清空筛选后恢复原来的分类偏好。可按成员名字、ID 或群组成员检索，支持多个关键词。

“定位当前”清除搜索和筛选、展开当前分类并滚动到正在交流的对话。搜索框旁的“新建”统一创建 Bot、涌现群聊、纯聊天和任务组。工作总览、历史搜索、例行任务和群组日程集中在底部“工作与工具”。点「聊天」或标志回到当前对话，并离开 City 与日常视图；已经打开的详情面板保持不动。再点当前对话只回到聊天，不重新载入记录。

键盘：Ctrl/⌘+K 搜索，Ctrl/⌘+B 收起或展开侧栏；搜索框用上下键进入名单，有关键词时 Enter 打开第一项。对话列表中用上下键、Home、End 移动，Enter 打开。快捷筛选可用左右键切换。Esc 先清空搜索，再收起菜单，最后关闭小屏侧栏。列表更新保留滚动和键盘焦点，不会自动跳回顶部。手机打开侧栏不会弹出键盘。


## 4.6 工作台布局

参考 [Grok Bot 的官方设计说明](https://x.ai/news/designing-grok-bot)，以持续存在的 Bot 与群聊名单组织界面。

左侧功能窄栏与名单分开：功能栏 64px，名单默认 360px，拖动右边缘可放大至 520px；较窄窗口会保留聊天区所需宽度。双击分隔线恢复默认宽度，也可聚焦分隔线后用左右键调整、Home 复原。收起名单后功能栏仍然保留，点击“聊天”即可展开。

Bot 与群聊使用大卡片显示：头像 44px，名称 15px，消息预览 13px，支持两行名称与两行预览。卡片包含最后交流时间、组件类型与真实状态。“全部 / Bot / 群聊 / 任务”快速切换；更多类型与运行状态放在筛选按钮中，避免挤占名单。

预览只读取各对话记录文件的有界尾部，展示最近完成的用户或 Bot 消息；工具活动和中断草稿不作为完成消息展示。预览最多 140 个 Unicode 字符并标明省略，完整原文保留。超长单条记录无法从尾部完整读取时显示“打开查看完整交流”，不把残缺记录当作消息。已知凭据在返回浏览器之前隐藏。内部咨询不进入用户名单。

中间聊天区统一调整标题、字号、正文与输入框的比例。右侧“详情”可以查看当前组件概览、成员、真实任务与审批入口；切换 Bot 或群组时随当前对话更新。宽屏时详情与聊天并列，窄屏按需打开并可用 Esc 关闭。小屏保留完整功能与大卡片，消息队列可以从“详情 → 任务”进入。

名单宽度、分类展开与外观保存在本机浏览器。没有重写 Bot 身份、模型、聊天、长期记忆或日常预算。首次进入默认打开主助手，组件总览改为从左侧功能栏按需打开。
