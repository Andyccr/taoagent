# 帝国之城（Empire City）

TaoAgent 内置的本机三维城市视图。每位真实成员一栋建筑，状态全部来自本机记录，画面运行时不调用任何模型，也不访问外网。

## 打开

侧栏第一项「城 帝国之城」，或设置 → 常规 → 帝国之城，或地址 `/#empire-city`（旧地址 `/#civilization` 仍可用）。

## 城市怎么来的

- 成员：`store.agents()` 中未归档的成员，新增成员下一次刷新（2.5 秒）自动建房；归档后自动拆除。
- 中央太和殿：默认由主助手 `main` 坐镇（它参与每个群）。如需改由其他成员坐镇，在 home/ 下建 `empire-city.json`：`{"leadAgentId": "成员 id"}`；该成员不存在或已归档时回到主助手。只有没有主助手时，才由最常担任群协调者的成员坐镇。殿顶的人物是你。
- 城区按成员职责关键词划分（无匹配时按标识分配并注明）：宫城（中式）、罗马工程区（穹顶/拱/引水渠）、希腊学园（柱廊神庙/剧场）、现代都会（玻璃塔），外围是现代天际线。
- 每环 6 块地；外环住满时自动扩建新环，并始终保留带围栏的「待建」用地。

## 状态与画面

| TaoAgent 记录 | 城市状态 | 画面 |
|---|---|---|
| 回合发言 running / 观察 checking | working | 窗户亮灯、人物工作、地面光环 |
| 60 秒内移交的待办任务 | working（移交方） | 信使拿着卷轴从移交方走到接收方 |
| 待批准的操作 | waiting | 灯笼点亮、等待图标 |
| 发言失败（暂停/中断除外） | error | 屋顶红烟、错误图标 |
| 20 秒内完成 | completed | 烟花 |
| running 超过 10 分钟且无心跳 / 记录无法读取 | stale | 建筑与人物变灰 |
| 本机服务连不上 | disconnected | 全城城门关闭、变灰 |
| 以上皆无 | idle | 安静的城 |

## 城市规模

成员所在的议事核心（中央大殿 + 3 环共 18 块用地）不变；核心之外的城市改为有机生成：固定种子，同一份名册总是得到同一座城。

- 护城河蜿蜒曲折，仍有 8 座桥；环路略带起伏，每 45° 一条放射大道缓慢弯曲；支路弯曲，带死胡同与小巷。
- 约 1300 块用地，尺寸约 5–9 米不等，沿道路布置、朝向最近道路，旋转、退界与高度带轻微抖动。现代塔楼越靠近天穹塔越高，偶有地标尖塔；公园、广场、集市散布在不规则位置。
- 城墙带（r 170–182）之外依次是：混合街区环（182–222，四种风格混住——现代塔楼挨着四合院、商铺住宅、柱廊、佛塔）、郊区（小屋）、工业区（仓库、工厂、筒仓）、东北角的港口（海面、码头、起重机），以及向外延伸到 r≈330 的农田（农舍、谷仓、田野，渐入乡野）。
- 约 760 块「可入驻」用地（各城区住宅/办公，加上外围小屋、商铺住宅与农舍）。核心 18 块住满后，新成员按「同风格 → 内环带 → 角度最近 → id」的固定顺序入驻，替换原填充建筑。
- 奇观尺度（约）：紫宸宫 ≈90×115、高~26；万佛塔 高~102；万里城关 长~100、高~34；雅典卫城 ≈70×56、高~36；大斗兽场 ≈56×46、高~30；万神殿 穹顶高~40；凯旋门 高~28；天穹塔 高~172。
- 8 座奇观不变：紫宸宫、万佛塔、万里城关（宫城）、雅典卫城（希腊学园）、大斗兽场、万神殿、凯旋门（罗马工程区）、天穹塔（现代都会）。悬停显示名称，点击镜头飞过去并在侧栏显示。
- 性能：填充建筑按「象限 × 内外环 × 种类 × 变体」实例化；道路、运河、公园为合并带状网格；田野单个 InstancedMesh；静态核心装饰、成员建筑与待建用地按材质合并（`bake.js`）；低画质关闭阴影与行道树，自动降级保留。远景总览只显示主助手的名字标签。
- 代码：`metropolis-plan.js`（规划与入驻）、`metropolis-roads.js` / `metropolis-streets.js`（路网与道路索引）、`metropolis.js`（渲染）、`bake.js`、`fillers-*.js`（含 `fillers-outer.js`）、`wonder-*.js`。

## 操作与观赏

- 侧栏可按姓名与状态搜索、筛选成员，列表与镜头同步。
- 「巡游奇观」「巡游成员」依次飞越；抵达奇观时有闪光。
- 小地图（M）点击定位；夜间模式（N）点亮窗灯与灯笼。
- 键盘：F 飞到主助手，1–8 直飞奇观，Esc 退出跟随或巡游。
- 城区地面为不规则拼块，内环更密；屋顶有天线、烟囱，街道有路灯。
- 港口有船，空中有鸟，工业区烟囱冒烟。

## 侧栏

使用情况（订阅额度显示 Unavailable，绝不编造）、城区镜头、成员、团队（即现有群聊；点击高亮成员）、最近动态（由回合、任务、审批记录推导，不含任何正文/参数）、任务、选中详情（职责、当前任务、所在团队、近期事件、跟随镜头）、显示设置。

- 「回放动态」：按时间顺序重演最近的真实事件，全程标注「回放 · 不是当前状态」，结束后回到实时状态。
- 「模拟文明」：纯浏览器模拟，标注清楚，不写入任何记录。

## 代码

- `civilization.ts` — 只读快照 `GET /api/civilization`（成员、状态、建筑、任务、移交、events、teams、leadSource）。
- `public/civilization.js` / `civilization.css` — 界面外壳、轮询、回放、详情。
- `public/city-entry.js` — 快照 → 场景（状态映射、成员名册、成员变化时重建城市）。
- `public/city/*` — 程序化三维城市（Three.js，移植自 virtual-office 原型）；`geo.js` 为合并几何构建器，城市相关文件见上文。
- `build-city.mjs` — 打包为 `public/city.bundle.js`（`npm run build:city`）。
- 测试：`tests/civilization.test.ts`、`tests/empire-city.test.ts`、可选浏览器测试 `tests/empire-city-browser.test.ts`。
